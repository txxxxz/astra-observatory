# 功能与资源验收

验收日期：2026-11-05。应用运行于 Linux arm64 Docker，浏览器连接 `http://127.0.0.1:8000`。性能测试的参数、吞吐和查询延迟见 [容量与吞吐实测](capacity-ceiling.md)。

## 数据正确性与恢复

- 37 项后端及压测脚本测试通过；其中 33 项后端测试也在 arm64 容器内通过，见 [容器测试日志](../evidence/docker-backend-tests.log)。测试覆盖消息去重、内容冲突、整批隔离、分类迁移、运行隔离及分页导出。
- 121 条协议样本导入后得到 2,080 个有效对象、分类版本 11、4 次重复和 2 条隔离，见 [样本重放记录](../evidence/sample-replay.json)。只读根文件系统部署后再次重放，全部识别为重复，见 [重复重放记录](../evidence/readonly-sample-replay.json)。
- 强制停止并重启应用后，21 条已确认消息的状态、内容哈希和原文一致，20 个对象逐字段一致，重试返回重复状态，见 [恢复记录](../evidence/recovery.json)。
- 基础压测的 4,685 个已确认批次均与数据库核对一致，见 [批次核对](../evidence/receipt-audit.json)。恢复测试覆盖应用进程崩溃；宿主断电和存储设备故障尚未测试。

## 浏览器操作

已在桌面 1440 × 900 和窄屏 390 × 844 下操作运行选择、分类及后代筛选、名称前缀、对象 ID、分页、点选、详情和导出，页面没有横向溢出，操作过程中未出现控制台错误。

- 分类、目录、详情和状态默认收起，按需展开。选择星点后显示详情；聚焦后按钮变为“回到原处”，返回时恢复此前视角，详情保持展开。
- 599 个和 3,000 个观测点均能随视口比例铺开。3 项布局测试覆盖宽窄屏边界、边缘分布、原始输入保留、空数据、单点和同坐标对象的排列。
- 同一场景使用一个 `frame_id / frame_kind / unit`；切换坐标系后，详情和筛选对应所选坐标系。展示布局拉近星群、增强纵深，详情和导出保留原始 XYZ。
- 星点提示位于底栏上方。在 1280 × 800 验证中，两者间距约 25.5 px；星点选择、近距聚焦和返回均可操作。
- 浏览器按“星体及后代 + 恒星名称前缀”筛选并下载 NDJSON，共 58 条、75,943 字节，名称全部匹配且保留完整属性，见 [下载记录](../evidence/browser-export.json)。

## 资源配置

应用限制为 **4 vCPU / 4 GiB**，独立发生器限制为 **1 vCPU / 256 MiB**，均无额外 swap。应用根文件系统只读，`/tmp` 使用上限 64 MiB 的 tmpfs，计入容器内存。实际配置见 [资源核查](../evidence/runtime-budget-recheck.json) 和 [压测容器配置](../evidence/capacity-ceiling/runtime-configuration.json)。

| 项目 | 存放位置与控制方式 | 计入 `/api/health.storage_bytes` |
|---|---|---|
| SQLite 主库、WAL、SHM | `/data` 持久卷；接入前检查目录大小和磁盘剩余空间 | 是 |
| 应用日志 | `/data/observatory.log`；每个文件 2 MiB，保留当前文件及 3 个备份，合计约 8 MiB | 是 |
| 应用 Docker 日志 | Docker 引擎管理；10 MiB × 3 个文件，合计约 30 MiB | 否，计入后台磁盘预算 |
| 应用镜像与容器层 | Docker 引擎存储；根文件系统只读 | 否，计入后台磁盘预算 |
| `/tmp` | 64 MiB tmpfs | 否，计入内存 |
| NDJSON 导出 | 后端分块读取并发送，浏览器或测试客户端下载 | 无后台导出文件 |
| 压测报告与截图 | 测试客户端保存，构建时由 `.dockerignore` 排除 | 否 |
| 发生器镜像与收据卷 | 独立发生器使用 | 单独统计 |

应用数据目录阈值为 **18 GiB（软限制）**，为 20 GiB 总预算中的镜像、日志及事务增长预留空间。接入时在写入锁内检查容量，并按请求大小预留事务空间；容量不足时返回错误，不确认新消息。历史数据由用户归档管理。

普通 Docker 命名卷没有容量硬限制。部署平台可用文件系统配额设置严格的磁盘上限；总占用应同时统计数据卷、运行镜像、容器层和 Docker 日志。开发构建缓存与历史镜像另占宿主磁盘。

本轮六档压测结束后，数据库累计保存 **2,447,800 个对象**，数据目录占用 **9.20 GiB**，应用容器内存采样峰值 **535.4 MiB**。各档最终导出数量与数据库一致，发生器已停止，见 [最终运行状态](../evidence/capacity-ceiling/runtime-after.json) 与 [完整压测报告](capacity-ceiling.md)。
