# 浏览器验收

2026-11-05，使用 Codex 内置浏览器（真实 WebGL），连接同源 Linux arm64 Docker 应用 `http://127.0.0.1:8000`。最终资源：`index-Dj07RCp0.js`、`index-BwweNBqS.css`。没有使用静态截图替代界面。

## 已实际操作

- 选择原始样本运行与两档真实负载运行；顶栏对象数与后端一致。
- 桌面 1440×900：分类及后代、名称前缀、对象 ID、下一页和稳定页码。
- 点选真实 Three.js 数据点：详情从「恒星 #0」变为「彗星 #287」；最终高规模点选「黑洞 #17421」，坐标框架 galaxy-0 / ly 与场景一致。
- 选中对象镜头聚焦、重置视角；切换 galaxy-1 / ly 和 local_surface / m，勾选“仅当前坐标系”筛选目录。
- 隔离记录窗口显示两条原始异常批次，点开读取原因、应用对象数0与完整原始体。
- 按“星体及后代 + 恒星名称前缀”实际点击导出链接，浏览器完成下载：58条、75,943字节，全部名称匹配且含完整attributes。SHA-256见 `evidence/browser-export.json`。
- 窄屏390×844：分类、探索、详情标签切换；选分类后回到探索，点列表后自动显示详情，筛选仍可操作。
- 1440×900与390×844均无文档横向溢出；窄屏指标区域可局部横向滚动。
- 336,600对象运行：当前galaxy-0有19,113个匹配坐标对象，场景仅绘制前3,000个，界面实测读数120FPS。浏览器与显示刷新率相关，此值只代表本次交互采样，不是跨设备保证。
- 正常流程控制台warn/error均为空；最终截图对应上线镜像。

## 可见质量与修复

1. 主操作区保持三栏工作台，点云和下方目录是核心，没有宣传页替代产品。
2. 暗墨底色、青绿强调、系统字体与统一线性图标保持一致；主目录字号由10px提高为12px。
3. 真实点使用DPR校正的可见尺寸；装饰星降低亮度并明确注明为背景装饰。
4. 保持XYZ等比坐标与单一frame，数据采样数量、单位和范围明确可见。
5. 桌面详情与窄屏独立详情页完整呈现对象属性；长文本与数组按需展开。
6. 审查发现的frame旧数据误标单位、分类迁移后旧子树结果、详情_meta字段覆盖已修复；源码与构建复核记录见review.md。
