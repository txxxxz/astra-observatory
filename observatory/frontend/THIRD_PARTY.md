# Visual sources

SpotlightCard.tsx and SpotlightCard.css are reused from React Bits (DavidHDev/react-bits), upstream main, retrieved 2026-11-05. Source: https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Components/SpotlightCard . License included in REACT_BITS_LICENSE.md.

The restrained panel entrance and dock hover interaction are CSS implementations inspired by Fade Content (https://reactbits.dev/animations/fade-content) and Dock (https://reactbits.dev/components/dock). The nebula borrows the calm flowing-background direction of Aurora (https://reactbits.dev/backgrounds/aurora), implemented as an original noise-texture shader in the existing Three.js scene. These three upstream components were not copied or installed. No GSAP, Motion, or additional WebGL runtime was added.

The star shader takes visual inspiration from Galaxy; observations retain their object identity while the documented display layout compresses spatial groups and stretches Z. Galaxy itself is not installed.
