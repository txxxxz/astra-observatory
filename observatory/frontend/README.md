# ASTRA 前端

React 19 + TypeScript + Vite + Three.js，生产产物由 FastAPI 同源提供。所有对象、统计、分类和状态均来自真实 API。

```sh
npm ci
npm run dev    # Vite /api 代理至 127.0.0.1:8000
npm run build # 类型检查及静态构建，输出 dist/
```

## 结构

- `src/App.tsx`：运行选择、轮询、稳定快照分页、筛选与各面板状态。
- `src/api.ts`：JSON 请求、10 秒超时、取消清理及显示格式。
- `CategoryTree`：当前分类树及分类变更。计数来自后端增量统计。
- `UniverseScene`：Three.js 批量点云、OrbitControls、光圈选中、镜头聚焦、实际 FPS；装饰星空不参与点选。
- `ObjectList`：名称前缀 / 对象 ID / 分类 / 当前坐标系筛选、游标翻页、直接流式下载链接。
- `Inspector`：原始对象和独立服务元数据；未知字段（包括 `_meta`）可完整展开。长文本折叠，大数组分段展开。
- `Diagnostics`：隔离、冲突和应用记录及原始消息查看。

## 行为边界

- 指标每 3 秒、运行列表每 5 秒更新。请求不重叠，10 秒超时。页面数据在断连时保留，并显示断连/陈旧状态。
- 新对象不会自动移动当前列表。用户点击“全站新增”或刷新后重新读取快照。翻页固定 `snapshot_max`；选中分类的分类版本变化会重新查询当前子树，避免迁移后保留错误成员；选中的对象保留。
- 每次点云最多 3,000 点，来自所选 frame_id/frame_kind/unit，按持久化顺序取前 N 个。展示布局拉近星群、增强 Z 轴纵深，并按视口比例铺开星点；每个可选星点仍对应原对象，详情和导出保留原始 XYZ。不同 frame 不混合；切换 frame 或筛选时先清除旧点。
- WebGL 不可用时仍可浏览列表、详情和导出。窗口后台或移动端隐藏场景时暂停 GPU 渲染。FPS 为实际渲染计时，非固定演示值。
- 筛选导出使用原生浏览器下载链接，不在 JavaScript 中累计 Blob；后端分块输出 NDJSON。
- 无在线字体、外部图片、分析 SDK 或密钥依赖；背景为轻量程序化装饰。
